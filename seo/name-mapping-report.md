# Name-spelling mapping (SEO plan step 1)

Generated 2026-11-06. This is the input table the per-name pages are built from:
**current site spelling → common searcher spelling → IAST → Devanagari → variants → page slug**.

Run `node seo/build-name-mapping.mjs` to rebuild every output from repo data.

## Inputs

| Input | Role |
|---|---|
| `public/mahakali_sahasranama_meanings.json` | Current English data (1,072 entries, meaning + elaboration) |
| `seo/data/legacy-devanagari-names.json` | Cached Devanagari **name only** from commit `824a649` (pre-English-only data). No Hindi prose, meanings, or UI were restored. |
| `seo/data/name-overrides.json` | 21 hand-verified corrections to legacy Devanagari spellings found during QA |

The legacy file had one Devanagari name per entry (`hindi_name`). It was removed from the
site because the Hindi *content* was expensive to maintain; only the name spelling is
reused here, and it is regenerated by script — nobody hand-maintains 1,072 rows.

## Pipeline

1. **Clean** the legacy Devanagari name (strip trailing romanized glosses such as
   `मन्त्रिणी (MANTRIṆĪ)`, normalize danda/punctuation).
2. **Devanagari → IAST** with `seo/lib/transliterate.mjs` (conjuncts, matras, anusvara,
   visarga, avagraha, nukta letters).
3. **IAST → readable English spelling**, using the conventions searchers type:
   `ś/ṣ → sh`, `ṛ → ri`, `c → ch`, `ch → chh`, anusvara assimilates
   (`Narasimha`, `samsara`, `vanshini`, `sankalpa`), `v → w` alternate form
   (`Ishvari`/`Ishwari`), `jñ → jñ` plus a `gy` alternate (`Gyanini`).
4. **Variants** per name: simple ASCII (`Smasana Kalika`), w-form (`...eshwari`),
   gy-form (`Gyanini`), no-space form, IAST (`Śmaśānakālikā`), and the site's current
   all-caps transliteration (`SHHMASHHANA KALIKA`) — kept as "also spelled" so existing
   anchors and the old spelling stay represented.
5. **Group repeated names.** A Sahasranama repeats some names; identical Devanagari
   becomes one page whose body lists every occurrence (number and meaning).
6. **QA**: compare the generated spelling against the current English elaboration text
   using a phonetic-compact comparison (case, diacritics, spacing, sh/s, ch/c, w/v
   collapse). Result: **1,064 / 1,072 found**; the 8 misses are elaboration typos or
   formatting quirks, listed below.

## Outputs

- `src/data/name-mapping.json` — canonical data imported by the Astro build:
  `rows` (one per Sahasranama position) and `pageGroups` (one per unique name page).
- `seo/name-mapping.csv` — same rows as a review sheet (Excel-friendly).
- `seo/data/legacy-devanagari-names.json` — extraction cache so rebuilds are offline.
- `seo/data/name-overrides.json` — corrections; add entries here, never edit the JSON.

## Spelling overrides (legacy data errors)

Legacy Devanagari came from the old Hindi data set and contained occasional errors
(Hindi-flavoured nukta spellings, dropped letters, missing visarga). Corrected:

`7, 18, 135, 213, 281, 283, 306, 345, 411, 442, 525, 578, 676, 677, 740, 760, 809, 843, 853, 953, 1050`

Examples:

- `18 KUNJAR'ESHHWARA GAMINI` — legacy `कुंजेश्वर` → corrected `कुञ्जरेश्वर` (missing र)
- `135 SHHYAMALA` — legacy `श्यामा` → corrected `श्यामला`
- `760 PARAMESHHANI` — legacy `परमेश्वरी` → corrected `परमेशानी` (site meaning is "Ishani")
- `853 DRIIDHRA-RUPI-SHHIVA-RUPA` — हिन्दी nukta `ड़` → Sanskrit `दृढ`

## Rows with no elaboration text match (not mapping errors)

These generated spellings are correct; the current English elaboration just spells the
name differently or has a typo (left unchanged — that belongs to a content pass):

- `503 KLESHHA NASHHINI` — elaboration starts "Kaleshha …" (typo)
- `576 NIMNA NABHIH` — elaboration "Nimna Nabih" (missing visarga h)
- `694 ANANGG'ANGKUSHH'ESHHWARI` — elaboration uses the site's `Anangg'Ankushh` form
- `715 SHHAKAMBHARY'ANU-KAMPINI` — elaboration `Shhaakambhary'anu-kampini`
- `842 BHAIRAVI TATHA` — name split across the sentence
- `853 DRIIDHRA-RUPI-SHHIVA-RUPA` — elaboration `Driidhra-Rupi`, corrected mapping uses `Dṛḍharūpī`
- `922 SWAYAM-BHU KUSUM'OTSANGGA` — elaboration uses `Kusum'otsangga`
- `1050 SADHAK'ANTAR-GATA DEVI` — elaboration `Sadhaak'antar-gata`

## Notes / known limitations

- **Primary URL slug** comes from the readable common spelling (`/names/shmashana-kalika/`).
  The simple transliteration (`Smasanakalika`) is included in the "also spelled" data,
  so the plan's tested query spelling is on the page even when it is not the slug.
- Word spacing follows the Devanagari (so `Ugraprabha`, `Shmashanavasini`), while the
  site's spaced spelling remains a variant.
- Variant generation is heuristic. It is deliberately generated, so improvements ship by
  editing `seo/lib/transliterate.mjs` or adding an override — not by editing 1,039 records.
- Duplicate-name pages are shared by both positions; range pages link each position to
  the same canonical page name.
